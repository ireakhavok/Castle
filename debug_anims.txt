Step 1: Verify Deformers and Weights in Parsing

Why? Deformers (skins/clusters) are present per your understanding, but if weights are uninitialized (e.g., array empty), animation won't deform the mesh. FBX parser assumes specific property types ('d' for weights); if the file uses 'f' or raw 'R', it skips, leading to zero weights. For static meshes like cube, no skin = no issue, but animation files need weights to apply transforms from separate file to main mesh vertices.
How to debug:
Add temporary Console.WriteLine in FBXParser.cs inside the cluster parsing loop (after parsing indexes/weights):C#Console.WriteLine($"Cluster for bone {boneIdx}: Indexes length = {indexes.Length}, Weights length = {weights.Length}");
if (weights.Length > 0) Console.WriteLine($"Sample weight: {weights[0]}");
Reload an animated model + separate animation file in AssetViewer. Check logs for cluster lengths. If weights.Length == 0 but deformers exist, parser bug (type mismatch). If >0, weights are parsed but not applied (check if perVertBones gets populated and normalized).
Also print model.HasSkin after parsing. For cube, expect false; for animated, true with non-zero bw.Count in perVertBones.


Step 2: Inspect Metadata for Limb/LimbNode Details

Why? Metadata (.json from ExportMetadata) will show raw FBX node types/properties without parser assumptions. This confirms if LimbNodes are joints (no 'Size', focus on rotation) vs Limbs (with 'Size' for visualization). If weights link to LimbNodes independently, animation should deform via joint hierarchy without bone-length assumptions. Non-animating suggests mismatch in bone remapping (name-based in LoadAnimation).
How to debug:
Load the model, find generated ._metadata.json.
Open in text editor/search for "LimbNode" or "Limb" nodes. Note their "Properties70" (e.g., LclTranslation, Size). If Size uninitialized (0 or missing), it's a joint—visualize as point, not line.
Search for "Deformer" and "Cluster"—check "Indexes" and "Weights" arrays. If empty, file issue or parser skip. Compare to Unity import (export same FBX to Unity, check Inspector for skin weights/bones).
